# Wallpapers

Drop image files here with these exact names and the wallpaper picker
(`apps/web/src/lib/wallpapers.ts`) will pick them up automatically —
no code changes needed. Recommended: 1920x1200+, JPG or WebP.

- `sonoma-day.jpg`
- `sonoma-night.jpg`
- `sequoia.jpg`
- `ventura.jpg`
- `monterey.jpg`
- `big-sur.jpg`

If a file is missing, that option falls back to a gradient swatch instead
of a broken image, so the picker stays usable either way.
